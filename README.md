# Magic Stones - Dynamic Programming Challenge

This project implements a solution to a classic dynamic programming problem:  
**Given a dragon with a certain amount of health and a set of magical stones that do damage, find the minimum number of stones required to slay the dragon.**

It also includes a performance test for bubble sort flip counts and visualizes the time complexity.

---

## Features

- **Top-Down DP** (`magic_stones_topdown`)
- **Bottom-Up DP** (`magic_stones_bottomup`)
- **Flip Count Sort Analyzer** (`count_flips`)
- Runtime analysis and plotting using `matplotlib`
